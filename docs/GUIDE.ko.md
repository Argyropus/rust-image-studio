## 0. 인터페이스 구성

```
┌──────────────────────────────────────────────────────────────────────┐
│ 상단 바: 앱 이름 · 모델 │ 엔진 상태 │ 한/EN │ ? 📁 로그 ⚙설정         │
├──────────────┬───────────────────────────────────────┬───────────────┤
│ 컨트롤 패널   │ 캔버스                                 │ 갤러리         │
│ 모드 5종      │ 결과 이미지 · 진행 상태                 │ 검색           │
│ 입력 이미지   │ 인페인팅 브러시 · 확장 미리보기          │ 썸네일 목록     │
│ 프롬프트      │                                       │               │
│ 비율·크기 …   │                                       │               │
│ [이미지 생성] │                                       │               │
└──────────────┴───────────────────────────────────────┴───────────────┘
```

- 컨트롤 패널과 갤러리는 경계선을 드래그해 폭을 조정할 수 있습니다.
- 언어, 설정, 프롬프트, 해상도, 시드, LoRA 구성, 갤러리 썸네일 크기는 종료 시 영구 저장되어 다음 세션에 그대로 복원됩니다.
- Linux에서는 내장 폰트의 글리프 지원 범위에 따라 일부 아이콘이 대체 글리프로 표시됩니다(예: ✕ → ×, 🖌 → ✏). 기능상 차이는 없습니다.

## 1. 최초 실행 및 초기 설정

압축을 해제한 디렉터리에서 `RustImageStudio.exe`를 실행하면 **처음 실행 준비** 화면이 표시되며, 별도 조작 없이 구성 요소 프로비저닝이 자동으로 시작됩니다.

| 화면 요소 | 기능 |
|---|---|
| 전체 진행률 표시줄 | 수신량 / 전체 용량 및 진행률. 창을 닫아도 다음 실행 시 **이어받기**로 재개됩니다. |
| **필수** 항목 | 추론 엔진, CUDA 런타임, 이미지 생성 모델, 텍스트 인코더, VAE. Windows에서는 Visual C++ 런타임이 미설치된 경우에만 선행 설치합니다(UAC 승인 1회). |
| **추가 기능** 항목 | 비전 모듈(편집·확장·사진 설명), 추천 LoRA 3종, 캡셔닝 엔진. 실패하더라도 기본 생성 기능은 유지되며, 해당 기능 사용 시점에 재시도할 수 있습니다. |
| 항목별 상태 | ✔ 완료 · 진행률 · "압축 푸는 중…" · "설치 중…" · "실패" |
| **중지** | 다운로드를 중단합니다. 현재 세션에서는 자동으로 재개되지 않습니다. |
| **⬇ 다운로드 시작** / **⟳ 다시 시도** | 중단 또는 오류 이후 프로비저닝을 재개합니다. 부분 수신된 파일은 HTTP Range 요청으로 이어받습니다. |
| NVIDIA 드라이버 경고 | 드라이버 미검출 시 안내 문구와 **드라이버 받기** 링크를 표시합니다. 드라이버는 애플리케이션이 설치할 수 없는 유일한 구성 요소입니다. |
| 디스크 공간 부족(적색) | 필요 용량 + 1GB의 여유 공간이 확보되지 않으면 시작 버튼이 비활성화됩니다. |
| **이미 받은 파일이 있다면 설정에서 경로 지정하기 →** | 보유 중인 모델 파일을 [설정](#6-설정)에서 직접 지정해 재다운로드를 생략합니다. |
| (Linux) 시스템 구성 요소 점검 | glibc, `libstdc++`, `libvulkan` 누락 시 설치할 패키지명을 제시합니다. 엔진 다운로드 실패 시에는 수동 빌드 명령과 **📋 명령 복사** 버튼을 제공합니다. |

프로비저닝이 완료되면 엔진이 자동으로 기동되며 "엔진 준비 완료" 알림이 표시됩니다.

## 3. 컨트롤 패널

상단부터 **모드 → 입력 이미지 → 프롬프트 → 비율·크기 → 시드·개수 → 고급 설정 → LoRA** 순으로 구성되며, 하단의 **빠른 모드 · 모델 · 이미지 생성** 영역은 항상 고정 표시됩니다. 각 카드는 제목 클릭으로 접을 수 있으며, 접힌 상태에서도 제목 줄에 현재 설정값이 요약 표시됩니다.

### 3.1 생성 모드

| 모드 | 동작 | 단축키 |
|---|---|---|
| **텍스트** | 프롬프트만으로 신규 이미지를 생성합니다(text-to-image). | Ctrl+1 |
| **변형** | 입력 이미지의 구도·색감을 기반으로 재생성합니다(img2img). | Ctrl+2 |
| **편집** | 자연어 지시문("배경을 바다로 바꿔줘")에 따라 이미지를 편집합니다. 참조 이미지 최대 3장, 비전 모듈 필요. | Ctrl+3 |
| **부분수정** | 브러시로 지정한 마스크 영역만 재생성하고 나머지는 보존합니다(인페인팅). | Ctrl+4 |
| **확장** | 캔버스 외곽을 확장해 장면을 연속 생성합니다(아웃페인팅). 원본 영역은 원 해상도로 보존됩니다. | Ctrl+5 |

- 텍스트 모드에서 이미지를 투입하면 편집 모드(비전 모듈 부재 시 변형 모드)로 자동 전환됩니다.
- 변형·부분수정·확장 모드는 단일 입력 이미지만 사용합니다.

### 3.2 입력 이미지 카드 (텍스트 모드에서는 비표시)

| 요소 | 기능 |
|---|---|
| **📋 붙여넣기** | 클립보드 이미지를 입력으로 지정합니다(Ctrl+V). |
| **📂 열기** | 파일 선택 대화상자(png, jpg, webp, bmp, 다중 선택 지원). |
| 드롭 영역 | 이미지를 드래그 앤 드롭하거나 클릭해 선택합니다. 갤러리 우클릭 → **입력 이미지로 사용**도 지원합니다. |
| 썸네일의 ✕ | 해당 입력을 제거합니다. |
| **＋** (편집 모드) | 참조 이미지를 추가합니다. 최대 3장이며, 좌상단 인덱스(1, 2, 3)로 프롬프트에서 "1번 이미지", "두 번째 이미지"처럼 지칭합니다. |

**변형 모드 전용**
- **변형 강도** 0.10~1.00(기본 0.60): 값이 높을수록 원본과의 편차가 커집니다. 하단에 실제 실행 단계 수가 표시되며, ↺로 권장값으로 복원합니다.

**편집 모드 전용**
- 비전 모듈 부재 시 **⬇ 비전 모듈 다운로드**(약 1.2GB) 버튼이 표시되며, 수신 완료 후 엔진이 자동 재기동됩니다.
- 첫 편집 요청 시 비전 모듈 로드를 위해 엔진이 1회 재기동될 수 있습니다.

**부분수정 모드 전용**
- **🖌 브러시** / **🧽 지우개**: 마스크 칠하기·지우기 전환.
- **반전**: 마스크 영역과 비마스크 영역을 반전합니다.
- **전체 지우기**: 마스크를 초기화합니다.
- **브러시 크기** 4~400px(기본 60). 캔버스 위에서 Ctrl+휠 또는 `[` `]`로도 조정할 수 있습니다.
- **수정 강도** 0.30~1.00(기본 0.85). 0.8~0.9를 권장하며, 1.0에서는 마스크 경계 밖까지 변화가 번질 수 있습니다.
- **🖌 마스크 편집으로 돌아가기**: 결과 보기에서 마스크 편집 화면으로 복귀합니다.

**확장 모드 전용**
- **빠른 선택**: `↔ 16:9`(좌우 확장) · `↕ 9:16`(상하 확장) · `⬜ 1:1`(정사각형) · `4:3` · `⤢ 줌아웃`(사방 1.5배). 입력 이미지가 이미 해당 비율이면 사방으로 소폭 확장합니다.
- **왼쪽 · 오른쪽 · 위 · 아래** 슬라이더(0~100%): 방향별 확장량. 캔버스의 확장 미리보기에서 드래그로도 조정할 수 있습니다.
- 해상도 정보: 원본 → 결과 해상도, 분할 패스 수, 예상 소요 시간.
- **INT8로 바꾸기**: INT8 모델 파일이 있을 때 표시되며, 확장 처리 속도가 약 35% 향상됩니다.
- **↔ 확장 미리보기로 돌아가기**: 결과 보기에서 확장 미리보기로 복귀합니다.
- 확장은 실패율을 낮추기 위해 Turbo 8단계 · CFG 1 · LoRA 비활성 · 빠른 모드 비활성으로 고정되며, 고급 설정과 LoRA 카드는 숨겨집니다.

### 3.3 프롬프트 카드

| 요소 | 기능 |
|---|---|
| **✨ 예시** | 현재 모드에 맞는 예시 프롬프트를 삽입합니다. 클릭할 때마다 다음 예시로 순환합니다. |
| **🖼 사진 설명** (확장 모드) | 입력 이미지를 GPU로 캡셔닝해 장면 설명을 생성·삽입합니다(약 20초). 생성 작업이 진행 중이면 완료 후 실행됩니다. |
| **가 글씨** | 이미지 내 한글 텍스트 삽입용 문장 템플릿을 추가합니다. `"여기에 문구"` 부분만 원하는 문구로 교체하십시오. |
| **🕘 최근** | 최근 프롬프트 이력(15개 표시, 30개 보관). 항목 클릭으로 재사용, 항목 옆 ✕로 개별 삭제, **🗑 최근 기록 모두 지우기**로 일괄 삭제합니다. |
| **✕** | 프롬프트 입력란을 초기화합니다. |
| 입력란 | 모드별 작성 가이드가 플레이스홀더로 표시되며, 하단에 글자 수가 표시됩니다. |
| **여러 프롬프트** | 한 줄에 하나씩 입력하면 상단부터 순차적으로 일괄 생성합니다. 생성 개수는 프롬프트별로 적용됩니다. |
| **💡 작성 요령** | 마우스 오버 시 동일 시드 비교 테스트로 검증한 프롬프트 작성 요령 6가지를 표시합니다. |
| **네거티브 프롬프트** | 배제할 요소(흐릿함, 저화질 등). CFG 1에서는 적용되지 않으므로 고급 설정에서 CFG를 높이십시오. |

- 확장 모드에서는 프롬프트를 **생략**할 수 있습니다. 본 앱이 생성한 PNG는 메타데이터의 장면 설명을, 일반 사진은 캡셔닝 엔진이 생성한 설명을 자동으로 채웁니다. 사용자가 직접 입력한 프롬프트는 덮어쓰지 않습니다.

### 3.4 비율 · 크기 카드

| 요소 | 기능 |
|---|---|
| **입력 이미지 비율 따르기** | 이미지 기반 모드에서 활성화 시(기본값) 입력 이미지의 종횡비를 유지합니다. |
| 비율 타일 | `1:1` 정사각 · `4:3` 가로 · `3:4` 세로 · `16:9` 와이드 · `9:16` 세로 영상. |
| **빠름 / 표준 / 고화질** | 출력 해상도(약 0.5 / 1.0 / 1.6 메가픽셀). 기본값은 표준(1:1 기준 1024×1024). |
| **직접 크기 지정** | 너비·높이를 직접 지정합니다(256~2048, 32의 배수로 자동 정렬). ⇄로 가로·세로를 교환합니다. |

확장 모드에서는 결과 종횡비가 확장 범위로 결정되므로 해상도만 선택합니다.

### 3.5 시드 · 개수 카드

| 요소 | 기능 |
|---|---|
| **랜덤 / 고정** | 랜덤은 매 생성마다 새 시드를, 고정은 동일 시드로 결과를 재현합니다. 랜덤 생성 후에도 마지막 시드가 입력란에 유지되므로 "고정"으로 전환해 즉시 재현할 수 있습니다. |
| 시드 값 | 드래그 또는 더블클릭으로 입력합니다. 다중 생성 시 시드, 시드+1, … 순으로 적용됩니다. |
| 🎲 | 신규 시드를 추첨해 고정합니다. |
| **개수 1~8** | 1회 요청당 생성 매수. |

### 3.6 고급 설정 카드 (기본 접힘)

| 요소 | 기능 |
|---|---|
| **샘플링 단계** | **Turbo 8단계(권장)** 또는 **직접 지정**(4~40). |
| **CFG** | 1.0~8.0(기본 1.0). Turbo 모델은 CFG 1에 최적화되어 있습니다. 값을 높이면 네거티브 프롬프트가 적용되나 소요 시간이 약 2배 증가합니다. |
| **생성 중 실시간 미리보기** | 샘플링 단계별 중간 결과를 표시합니다(기본 활성). |
| **↺ 모두 권장값으로** | 단계·CFG·강도·LoRA 강도·미리보기를 권장값으로 일괄 복원합니다. 프롬프트·해상도·시드는 유지됩니다. |

### 3.7 LoRA 카드

LoRA는 기반 모델에 특정 표현 능력을 추가하는 경량 어댑터 가중치입니다. `models/loras` 디렉터리의 파일이 목록에 표시됩니다.

| 요소 | 기능 |
|---|---|
| **폴더 열기** | LoRA 디렉터리를 엽니다. `.safetensors` 파일을 배치하십시오. |
| ⟳ | 디렉터리를 재스캔합니다. 새 파일은 엔진 재기동 없이 즉시 사용할 수 있습니다. |
| 체크박스 + 이름 | 활성/비활성 전환. 우측 수치는 **적용 강도**(0.00~2.00, 기본 1.00)입니다. |
| **Lightning 4단계 고속** | 4단계 샘플링으로 장당 약 12초(8단계 약 18초). 변형·부분수정에서는 자동 제외됩니다. |
| **편집 구도 고정** | 편집 결과의 구도·위치를 원본에 고정합니다. 대형 객체 제거나 포즈 변경 편집에서는 비활성화하십시오. 편집 모드 전용. |
| **다각도 재촬영** | 단일 입력 이미지를 다른 카메라 각도에서 재촬영합니다(배경은 회색 스튜디오로 전환). 활성화 시 **카메라 방향 다이얼**(12방향), **카메라 높이**(눈높이 · 30° · 60° · 위), **가까이(클로즈업)** 옵션이 표시되며, 선택에 따라 프롬프트가 자동 구성됩니다. 각도 변화가 없으면 강도를 0.8로 낮추십시오. 편집 모드 전용. |
| **편집 모드로** | 편집 전용 LoRA를 다른 모드에서 활성화했을 때 표시되는 전환 바로가기. |
| **추천 LoRA 받기** | 디렉터리에 없는 추천 LoRA를 원클릭으로 수신하며, 수신 완료 후 자동 활성화됩니다. |

상호 배타적인 LoRA 조합(고속 LoRA 2종, "편집 구도 고정"과 "다각도 재촬영")은 한쪽 활성화 시 다른 쪽이 자동 비활성화되고 알림이 표시됩니다.

### 3.8 하단 고정 영역: 빠른 모드 · 모델 · 이미지 생성

| 요소 | 기능 |
|---|---|
| **⚡ 빠른 모드** | Spectrum 단계 캐시로 8단계 중 일부를 예측값으로 대체해 약 23% 가속합니다. 결과 편차는 육안으로 거의 구분되지 않는 수준입니다. 확장 모드에서는 적용되지 않습니다. |
| **모델: … ▾** | **표준 · Q4_K_M**(RAM 사용량 최소화) 또는 **고화질·고속 · INT8 텐서코어**(반복 생성 고속화, 원본 모델에 근접한 화질). 전환 시 엔진이 재기동됩니다(약 40초). 모델 파일이 없으면 설정에서 수신할 수 있습니다. |

생성 요청이 거부되면 알림으로 사유를 안내합니다(프롬프트 누락, 입력 이미지 누락, 인페인팅 마스크 미지정 등).

## 4. 캔버스

### 4.1 시작 화면

- **샘플로 체험하기 · 폰케이스 교체**: **샘플 불러오기**를 실행하면 모델 사진·케이스 디자인·지시문이 편집 모드에 자동 구성됩니다. **이미지 생성**만 실행하면 됩니다.
- **예시로 시작하기**: 예시 프롬프트 3종. 클릭 시 프롬프트에 삽입됩니다.

### 4.2 결과 보기 및 도구 모음

이미지 상단에 프롬프트와 메타 정보(모드 · 해상도 · 시드 · 소요 시간 · 생성 일시)가 표시되며, 하단에 도구 모음이 배치됩니다. 창 폭이 좁으면 아이콘만 표시되고 마우스 오버 시 명칭이 나타납니다.

| 버튼 | 기능 |
|---|---|
| **불러오기** | 해당 이미지의 프롬프트·시드(고정)·해상도·모드·LoRA 구성 등을 컨트롤 패널에 그대로 적용합니다. 결과 재현 및 파라미터 미세 조정에 활용합니다. |
| **확장 ▾** | 해당 이미지를 즉시 확장 생성합니다: 좌우 확장(16:9) · 상하 확장(9:16) · 정사각형(1:1) · 4:3 · 줌 아웃(사방 1.5배). **⚙ 직접 조절하기…**는 생성 없이 확장 모드로만 전환합니다. |
| **자연스럽게** | 합성 이질감이 있는 휴대폰 케이스를 장면의 조명·반사·음영에 맞게 보정합니다. 직전 편집의 케이스 이미지(참조 2)를 함께 사용해 디자인을 보존하며, 클릭 즉시 생성합니다(약 75초). |
| **입력으로** | 해당 이미지를 변형·편집의 입력으로 지정합니다. |
| **마스크 편집** (부분수정 모드) | 마스크 편집 화면으로 복귀합니다. |
| 🔍 크게 보기 | 전체 화면 뷰어(F). |
| 복사 | 이미지를 클립보드에 복사합니다(Ctrl+Shift+C). |
| 다른 이름으로 저장 | PNG(원본 그대로, 생성 메타데이터 포함) · WebP(무손실, 고압축) · JPEG(품질 92, 웹 게시용) 중 선택해 저장합니다(Ctrl+S). |
| 폴더에서 보기 | 파일이 위치한 디렉터리를 엽니다. |
| 🗑 삭제 | 확인 대화상자를 거쳐 휴지통으로 이동합니다(복원 가능). |

이미지를 더블클릭해도 전체 화면 뷰어가 열립니다.

### 4.3 생성 진행 중

미리보기와 진행률 표시줄이 표시됩니다. 처리 단계(프롬프트 인코딩 → 샘플링 N/M → 디코딩), 경과 시간, 잔여 시간 추정치를 확인할 수 있으며, **취소**는 현재 작업만 중단합니다. 다단계 확장 시 "확장 k/n단계"로 표시되고, 신규 영역의 공백이 감지되면 자동으로 재생성합니다.

### 4.4 인페인팅 마스크 편집 화면

- 좌클릭으로 마스크를 칠하고, 우클릭으로 지웁니다. 마스크 영역은 반투명 적색으로 표시됩니다.
- Ctrl+휠 또는 `[` `]`로 브러시 크기를 조정합니다.
- **결과 보기**: 갤러리에서 선택한 이미지를 표시합니다.

### 4.5 확장 미리보기

- 가장자리 또는 모서리를 바깥으로 드래그하면 확장되고, 안쪽으로 드래그하면 축소됩니다. 이미지 내부 임의 지점을 드래그해도 가장 가까운 변이 조정됩니다.
- ◀ ▶ ▲ ▼ 화살표: 클릭 시 해당 방향 +10%, 우클릭 시 −10%.
- 빗금 영역이 신규 생성 영역이며, 각 방향의 확장 비율이 표시됩니다.
- **↺ 초기화**: 모든 방향의 확장량을 0으로 초기화합니다. **결과 보기**: 결과 화면으로 전환합니다.

### 4.6 전체 화면 뷰어

휠로 커서 기준 확대·축소, 드래그로 이동, 더블클릭으로 배율 초기화, ←/→로 이전·다음 이미지 탐색, Esc 또는 우상단 ✕로 종료합니다.

## 6. 설정

상단 바의 ⚙ **설정**으로 엽니다. 변경 사항은 **저장하고 엔진 재시작** 실행 시에만 적용되며, ✕ 또는 Esc로 닫으면 폐기됩니다.

| 항목 | 기능 |
|---|---|
| **생성 모델** | **표준 · Q4_K_M (4.2GB)**: RAM 사용량 최소화. **고화질·고속 · INT8 텐서코어 (7.3GB)**: 단계당 처리 속도 향상 및 원본 모델에 근접한 화질. 파일이 없으면 **⬇ 다운로드 (7.3GB)** 버튼이 표시됩니다. |
| **파일 경로** | 엔진 폴더 · Q4 모델 · INT8 모델 · 텍스트 인코더 · VAE · 출력 폴더. 📂로 탐색하며, 우측에 ✔(확인) / ✖ 없음 / 새 폴더 상태가 표시됩니다. 출력 폴더를 변경하면 갤러리도 해당 경로 기준으로 재구성됩니다. |
| **메모리 · 성능** | 메모리 배치 정책(VRAM 6GB 상한)을 설명합니다. |
| **시작할 때 예열하기 (권장)** | 엔진 기동 직후 저해상도 이미지를 1회 사전 생성해 첫 생성 지연을 단축합니다(약 36초 → 18초). |
| **추가 인자** | 고급 사용자용 엔진 인자(예: `--max-vram 7`). 일반적으로 비워 두십시오. |
| **기본값** | 설정을 기본값으로 복원합니다(저장 시 적용, 최근 프롬프트 이력은 유지). |
| **저장하고 엔진 재시작** | 변경 사항을 적용하고 엔진을 재기동합니다. 진행 중인 작업은 취소됩니다. |

UI 언어는 설정이 아닌 상단 바의 **한 / EN**에서 전환합니다.

## 10. 파일 시스템 구조

모든 데이터는 실행 파일과 같은 디렉터리에 저장되므로, 디렉터리 단위로 이동·백업할 수 있는 포터블 구조입니다.

| 경로 | 내용 |
|---|---|
| `runtime\` | 추론 엔진과 CUDA 런타임 (`runtime\llama\`는 캡셔닝 엔진) |
| `models\` | 이미지 생성 모델, 텍스트 인코더, VAE, 비전 모듈 |
| `models\loras\` | LoRA 가중치. 배치 후 LoRA 카드의 ⟳로 재스캔합니다. |
| `outputs\` | 결과 이미지(`날짜_시각_시드.png`), 갤러리 인덱스(`history.json`), 썸네일 캐시(`.thumbs`) |
| 설정 | Windows `%APPDATA%\Rust Image Studio`, Linux `~/.local/share/rustimagestudio` |

결과 PNG에는 프롬프트·시드·해상도·LoRA 구성 등 생성 메타데이터가 내장되어 있어, 이후 드롭만으로 동일한 설정을 복원할 수 있습니다.

## 11. 알림 및 트러블슈팅

알림은 화면 하단 중앙에 4초간 표시됩니다. 상태 표시 색상: **녹색 = 성공**, **주황 = 경고**, **적색 = 오류**, **회색 = 정보**.

| 증상 | 조치 |
|---|---|
| 상단 바가 **엔진 꺼짐** | 상태 표시를 클릭해 엔진을 기동합니다(약 40초). |
| 상단 바가 **오류** | 클릭해 재기동합니다. 재발 시 **로그 → 📋 전체 복사**로 로그를 수집해 보고하십시오. |
| 생성 버튼 비활성 | 엔진이 꺼져 있거나 오류 상태입니다. 상단 바의 상태 표시를 클릭하십시오. |
| 편집 모드 실행 불가 | 비전 모듈이 필요합니다. 입력 이미지 카드의 **⬇ 비전 모듈 다운로드**를 실행하십시오. |
| "일부 추가 파일을 받지 못했습니다" | 기본 생성 기능은 정상 동작하며, 해당 기능 사용 시 재수신할 수 있습니다. |
| 이미지를 실수로 삭제함 | Windows 휴지통(Linux는 휴지통)에서 복원하십시오. |
| 모델 파일을 이미 보유함 | 설정의 **파일 경로**에서 지정하면 재다운로드하지 않습니다. |
